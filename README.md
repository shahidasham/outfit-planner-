# Outfit Planner System

## Project Description
Outfit Planner System is a web-based application that helps users plan their daily outfits for the week. Users can select outfits, filter categories, view dashboard analytics, and manage weekly outfit planning easily in a modern interface.

## Features Included

- Outfit selection by category (Formal, Casual, Sport, Party)
- Search and filter outfits
- Weekly outfit planner (Monday–Friday)
- Favorite outfit feature
- Dashboard analytics (charts using Chart.js)
- Save planner data using localStorage
- Random outfit generator for the week
- Clear planner function
- Mobile-friendly responsive design

## Frameworks / Libraries Used

- HTML5 – Structure of the website
- CSS3 – Styling and layout design
- JavaScript – Functionality and interactivity
- Bootstrap 5 – Responsive UI framework
- Chart.js – Data visualization for dashboard charts
- LocalStorage API – Store user planner data in browser
